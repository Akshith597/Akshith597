## 🚀 Featured Projects

### 🚚 Logistics Control Tower

**Where are delivery performance and fulfillment breaking down?**

A logistics analytics workflow across **98,595 synthetic shipments**, connecting Python extraction, DuckDB, a SQL shipment-grain star schema, quality checks, and Power BI / Streamlit reporting.

- Tracks **76.5% on-time delivery** and **62.4% OTIF** in the full benchmark.
- Aggregates child records before joins to prevent double counting.
- Documents KPI eligibility, dashboard QA, and improvement scenarios.

**Stack:** Python · SQL · DuckDB · Power BI · Streamlit

🔗 [Explore the case study](https://github.com/Akshith597/logistics-control-tower) · [Try the interactive demo](https://logistics-control-tow.streamlit.app/)

### 📈 Meridian Sales Diagnostic

**Why is the Southern region missing its revenue target?**

A sales performance investigation using **SQL, Python, and Excel**, with an interactive dashboard covering **7,742 validated opportunities**.

- Identifies **84.1% target attainment** and a **23.9 percentage-point win-rate gap** versus other regions.
- Reconciles revenue to all **40 region-quarter target records within $0.01**.
- Prioritizes conversion coaching, discount controls, and large-deal reviews.

**Stack:** SQL · Python · Excel · Interactive dashboard

🔗 [Explore the case study](https://github.com/Akshith597/meridian_sales_portfolio) · [Try the interactive dashboard](https://akshith597.github.io/meridian_sales_portfolio/)

> These case studies use fictional or synthetic data. Findings and opportunity scenarios are portfolio demonstrations, not realized business impact. The logistics live demo uses a separate dataset from the full benchmark.
